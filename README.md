# 🎙️ Voice Pro AI

🚀 AI Voiceover Studio with long-form speech generation, realistic voices, and voice cloning.

---

## ✨ Features

* 🎤 40+ AI Voices (Male & Female)
* 🌍 Multi-language support (English, Urdu & more)
* ⏱️ Long-form generation (up to 2 hours)
* 🧠 Smart chunk processing (handles large text)
* 🧬 Voice cloning (custom voices)
* ⚡ Fast & lightweight

## 🚀 Installation

```bash
git clone https://github.com/adeelkhan6261/voice-pro-ai.git
cd voice-pro-ai
pip install -r requirements.txt
python main.py
```
